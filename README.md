# Restaurant-Sales-Analysis-PowerBI
An end-to-end data analytics project showcasing a modern Power BI dashboard for restaurant performance. Features SQL querying, data modeling, and advanced DAX to visualize $2.9B in sales with custom tooltips and drill-through functionality.


Restaurant Performance Analytics Dashboard 🚀
Project Overview
This is an end-to-end data analytics project developed as part of the Big Data course at ITI Tanta Branch. The project transforms raw restaurant operational data into a high-end, interactive Business Intelligence solution. It analyzes over $2.9B in total sales across multiple branches (Cairo, Giza, Alexandria, etc.) to provide actionable executive insights.

Databricks Notebook: View Analysis Logic

🛠️ Tech Stack & Skills
Data Extraction & Transformation: SQL Server & Power Query (ETL).

Advanced Analytics: Databricks for scalable data processing.

Data Modeling: Implementation of star schema and complex DAX measures.

Visualization: Power BI Desktop with a focus on "Premium Dark" aesthetic.

📊 Key Dashboards
1. Executive Overview
Focuses on high-level KPIs including:

Total Sales & Growth: Real-time tracking with dynamic growth indicators (🔼/🔽).

Sales Trends: Analysis of performance over time (2020-2025).

Branch Performance: Regional breakdown of revenue.

2. Item & Customer Insights
Provides granular details on:

Customer Behavior: Identifying top customers and rating patterns.

Product Analysis: Identifying best-selling categories like "Grills" and "Tajine".

Advanced UI: Integrated Drill-through and Custom Tooltips for detailed customer metrics.
